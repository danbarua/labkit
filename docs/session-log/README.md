# Session log

Mechanical wrap-ups, one per working session, written by the `wrap` skill
(`.claude/skills/wrap/`) and usually triggered by its Stop hook rather than by
anyone remembering. Each entry records the goal in a line, what changed, the
commands that verified it with their real output, what was left open, and the
exact next step.

**This is not `docs/project-journal/`.** That sequence is a curated argument —
each entry is a decision and the reasoning behind it, and CLAUDE.md points
readers at the newest few for what is true now. These are a handover for the
next session, and are disposable in a way the journal is not. Numbering here is
independent and starts at `001`.

If a wrap turns out to contain a real decision, that decision belongs in the
journal as well, in the journal's own terms — not by reference to a file here.
