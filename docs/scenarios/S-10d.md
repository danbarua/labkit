# S-10d — The order a run read its inputs in

A run takes the difference between two series, and a re-run reads the same two records the other way round. The same records are on both sides, so nothing differs, and the record still shows the order each run read them in.

6 acts, one voice.

```mermaid
sequenceDiagram
    actor Researcher
    participant R as LabKit
    Researcher->>R: openEnquiry do the two series differ?
    Researcher->>R: recordObservations x2
    Researcher->>R: recordAnalysis difference of the two series
    R-->>Researcher: COMP_4
    Researcher->>R: conclude the two series differ in magnitude
    Researcher->>R: reverify difference of the two series
```
