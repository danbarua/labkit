# S-10 — Rerunning is not reproducing

An old result says the protocol converges, but nobody wrote down what it started from. Running it again and recording the new result as a second analysis makes the two look like independent confirmation of each other.

6 acts, one voice.

```mermaid
sequenceDiagram
    actor Researcher
    participant R as LabKit
    Researcher->>R: openEnquiry does the annealed protocol converge below tolerance?
    Researcher->>R: recordAnalysis annealing-v1
    R-->>Researcher: COMP_2
    Researcher->>R: conclude the annealed protocol converges below tolerance
    Researcher->>R: recordObservations seed 4, tolerance 1e-6, 512 steps
    Researcher->>R: recordAnalysis annealing-v1, re-run
    R-->>Researcher: COMP_5
    Researcher->>R: conclude the annealed protocol converges below tolerance
```
